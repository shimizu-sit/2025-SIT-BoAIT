# 情報処理応用基礎

## 授業のねらい

本授業では，情報処理技術の様々な応用分野として，マルチメディア処理技術（CG／画像処理等），ユーザインタフェース関連技術
（Web／GUI等）の専門知識を得ることを目的とする．そして，当該分野における現状の課題を認識し，その解決策を自ら考えるスキルをつけることが本授業の狙いである．

## 授業の進め方

本授業では，講義による基礎知識の学習とともに，演習を通して、知識の習得を図る．また、これら情報処理技術を応用したシステムについてデザイン・評価・考察を行う．また，実習やディスカッションを行いながら，課題や解決方法を自ら見いだす能力を養成する．
